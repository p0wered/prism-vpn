# PrismVPN — проектный документ

> Pet-проект для портфолио. Лендинг + dashboard вымышленного VPN-сервиса.
> Главный акцент — **дизайн**: тёмная премиум-тема, эстетика Apple последних лет (Liquid Glass).
> Реального VPN не существует, все данные и функции — mock.

---

## 1. Концепция и смысловая часть

### Позиционирование

PrismVPN — сервис с тремя смысловыми столпами (на них опирается весь текст сайта):

1. **Обход блокировок** — основной сценарий: доступ к заблокированным государством сервисам. Современные протоколы, устойчивые к DPI.
2. **Приватность** — анонимное использование интернета, no-logs, шифрование.
3. **Гейминг** — выделенные игровые сервера: низкий пинг, минимальные потери пакетов, без троттлинга.

### Модель работы (важно для dashboard)

На сайте/в дашборде **нет кнопки Connect и функционала подключения**. Модель как у панелей Marzban/Remnawave: пользователь покупает подписку → получает ссылку-подписку / QR-код / конфиги → подключается через **внешние клиенты** (v2RayTun, Happ, Streisand, Hiddify и т.п.). Dashboard — это личный кабинет: статистика, подписка, сервера, настройки.

### Языки

Английский + русский (i18n). Основной для портфолио — английский.

## 2. Дизайн-система

### Референсы (папка `refs/`)

- `refs/ai_2x.png`, `refs/games_2x.png`, `refs/machinelearningandai_2x.png` — референсы стиля ассетов (3D-стекло/хром, холодное бело-голубое свечение на чёрном). **Это именно референсы** — финальные ассеты будут делаться в таком же стиле, но с другими объектами под тематику VPN.
- `refs/img.png` — bento grid с презентации iPhone 15 Pro (референс сетки features).

### Цвета

Токены живут в `src/index.css` (`@theme` Tailwind v4). Дефолтная палитра Tailwind **сброшена** (`--color-*: initial`) — любой цвет только из токенов, так автоматически соблюдается правило одного акцента.

| Токен               | Utility            | Значение (стартовое)               | Назначение                                                      |
| ------------------- | ------------------ | ---------------------------------- | --------------------------------------------------------------- |
| `--color-bg`        | `bg-bg`            | `#000000`                          | Фон страницы (чистый чёрный)                                    |
| `--color-surface-1` | `bg-surface-1`     | `#0A0A0C`                          | Фон карточек (elevation 1)                                      |
| `--color-surface-2` | `bg-surface-2`     | `#111114`                          | Elevation 2 (hover, вложенные блоки)                            |
| `--color-fg`        | `text-fg`          | `#F5F5F7`                          | Основной текст (эппловский off-white)                           |
| `--color-fg-muted`  | `text-fg-muted`    | `#A1A1A6`                          | Описания, подписи                                               |
| `--color-accent`    | `bg-accent` и т.п. | `#5EA2FF` (уточнить на реализации) | **Единственный** акцент — ледяной голубой, под свечение ассетов |

Правила:

- **Один акцентный цвет, не более.** Несмотря на нейминг «Prism», радугу/спектр в UI не тащим. Допустимы только едва заметные спектральные блики как «физика стекла» (грани, glare) — и то по ситуации, приоритет у чистого стиля Apple.
- Тёплых цветов нет нигде.
- Карточки всегда заметно светлее фона — иначе не читаются стекло и бордеры.

### GlassCard — базовый компонент карточки

Единый переиспользуемый компонент для всех карточек/блоков (bento, pricing, dashboard-виджеты):

1. **Градиентный бордер «свет сверху»** — не solid: псевдоэлемент с `padding: 1px` + `mask-composite`, фон `linear-gradient` сверху вниз от `rgba(255,255,255,.25)` до почти нуля. Имитация света, падающего сверху.
2. **Hover-подсветка от курсора (spotlight)** — CSS-переменные `--x/--y` обновляются от позиции мыши, два слоя:
   - `radial-gradient` подсветка фона карточки вокруг курсора;
   - усиление градиентного бордера рядом с курсором.
     База — SpotlightCard из React Bits, дорабатываем исходник.
3. Скругления крупные (Apple-like, ориентир 20–28px), фон `--surface-1`.

### Grain

Едва заметный шум на фоне (Hero, возможно другие крупные секции — не глобально):

- инлайновый SVG `feTurbulence` или тайл-PNG, `opacity: 0.03–0.05`;
- **статичный**, не анимированный (GPU + не отвлекает).

### Типографика

- **Geist** — основной (кириллица поддерживается с v1.3).
- **Geist Mono** — технические элементы: список серверов, IP, пинг, трафик, конфиги.
- Подключение через CSS-переменные (`--font-sans`, `--font-mono`) — замена шрифта бесплатна.
- Альтернативы на случай замены: Inter, Manrope, Onest, Golos Text (у двух последних лучшая кириллица); моно — JetBrains Mono.
- Bento-карточки: крупный заголовок + **короткое описание в 1–2 строки** цветом `--text-secondary`. Больше текста, чем у Apple (у них часто только заголовок), но описания держим максимально сжатыми — «воздух» важнее полноты.

### Анимации и движение

- **Framer Motion** — reveal-анимации при скролле (`whileInView`), микровзаимодействия, переходы.
- **Fullscreen-композиция, но НЕ scroll-jacking.** Обычный нативный скролл. Hero — строго `100vh`. Допустим мягкий `scroll-snap: proximity` на ключевых секциях, mandatory — запрещён.
- Возможна одна sticky-секция со scroll-linked анимацией как «вау-момент» (решим на реализации).
- **`prefers-reduced-motion` обязателен**: отключение/упрощение анимаций + статичный fallback вместо WebGL-фона.

### React Bits — правила использования

- Источник готовых эффектных фонов и компонентов-основ. Код открытый — **правим исходники напрямую**, не ограничиваемся их пропсами. Можно брать из компонента отдельный приём/эффект, а не компонент целиком.
- **Максимум один WebGL-фон на страницу — только в Hero.** Остальные эффекты — CSS.
- Не тащим много разных компонентов (стилистический винегрет), всё перекрашиваем в наши токены.

### Недостающая графика

3D-ассетов будет мало — добираем **CSS/SVG в том же стиле**: glow-цифры («10 Gbps», «94 страны», «0 логов»), светящиеся линии-маршруты, типографские карточки. Финальный вид — смотреть на реальной реализации.

## 3. Техстек

| Что                 | Выбор                                                                          |
| ------------------- | ------------------------------------------------------------------------------ |
| Сборка              | **Vite 8** (SPA)                                                               |
| Язык                | **React 19 + TypeScript 6**                                                    |
| Стили               | **Tailwind CSS v4** (`@tailwindcss/vite`) + дизайн-токены в `@theme`           |
| Анимации            | **Motion** (пакет `motion` — преемник framer-motion, импорт из `motion/react`) |
| UI-основы           | **React Bits** (исходники, дорабатываем)                                       |
| Роутинг             | **React Router v8** (`react-router`)                                           |
| Шрифты              | **@fontsource-variable/geist(-mono)** — self-hosted, сабсеты latin + cyrillic  |
| Линт/формат         | **oxlint** (пришёл с шаблоном Vite вместо ESLint) + **Prettier**               |
| Графики (dashboard) | Recharts или кастомные SVG — решим на реализации                               |
| i18n                | EN + RU (библиотека — решим, кандидат i18next)                                 |
| Деплой              | Vercel / Netlify (уточним)                                                     |

- SSR/SEO не нужны (pet-проект) — поэтому Vite, а не Next.
- **Полный адаптив всего** — и лендинга, и dashboard.
- Целимся в хороший Lighthouse: лениво грузим WebGL-фон и тяжёлые ассеты, следим за бандлом.

## 4. Структура лендинга

Стартовый состав (будет дополняться):

1. **Hero** — 100vh, WebGL-фон из React Bits (перекрашенный под палитру), grain, заголовок, CTA. Возможно hero-ассет в стиле референсов.
2. **Features** — bento grid по мотивам Apple. Карточки: заголовок + краткое описание, часть с ассетами/CSS-графикой. Смысловое наполнение из трёх столпов: обход блокировок, приватность (no-logs, шифрование), игровые сервера (пинг, packet loss), плюс технические фичи (протоколы, скорость, количество стран/серверов, мультиустройства).
3. **Pricing** — 3 фейковых тарифа на GlassCard (различия: трафик/устройства/игровые сервера).
4. **FAQ** — аккордеон. Темы: как подключиться (внешние клиенты), какие приложения поддерживаются, что с логами, работает ли при блокировках, возвраты и т.п.
5. Footer + финальный CTA.

_Кандидаты на добавление позже: секция скорости/серверов с числами, секция «как это работает» (3 шага: подписка → ссылка/QR → клиент), Privacy-манифест._

## 5. Dashboard (вариант «полноценное мини-приложение»)

Все данные — mock. Фейковый flow: логин с лендинга → dashboard.

Страницы:

- **Login** — фейковая авторизация (любые креды пускают).
- **Overview** — статус подписки (активна/до какого числа), использованный трафик (график), количество устройств, быстрые действия.
- **Subscription** — ссылка-подписка (копирование), QR-код, инструкции по клиентам (v2RayTun, Happ, Streisand…), управление тарифом.
- **Servers** — список серверов: страна/флаг, город, пинг, нагрузка, тип (обычный/игровой). Geist Mono для цифр. Фильтры/поиск.
- **Settings** — настройки аккаунта, язык, смена пароля (mock).

Dashboard использует ту же дизайн-систему (GlassCard, токены, шрифты), что и лендинг.

## 7. Открытые вопросы

- Точное значение `--accent` — подобрать на живой странице рядом с ассетами.
- Какой именно WebGL-фон React Bits для Hero — выбрать на этапе 2 из 2–3 кандидатов.
- Логотип: кандидат — абстрактный «узел» в стиле `ai_2x.png` (петля ≈ запутанный маршрут трафика).
- Recharts vs кастомные SVG-графики.
- Хостинг: Vercel или Netlify.
- Sticky-секция со scroll-linked анимацией — делать ли и где.
